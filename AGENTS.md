# Agent notes

## Git

Work on **`main`**. Commit and push there. Do not open extra branches or PRs unless two changes must stay isolated or the user asks.

Details: `.cursor/rules/git-workflow.mdc`.

## Run locally

```bash
npm start    # http://localhost:3000
npm run fetch
npm run check
```

Hard-refresh the browser after UI changes. Keys live in `localStorage`, not the repo.
